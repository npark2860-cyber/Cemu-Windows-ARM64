## 프로파일에서 확인한 후속 후보

INT8의 가장 큰 개별 NODE 항목은 `Transpose_token_214_2:OpId_22`로, warmup을 제외한10회 평균56,271,239.6cycles였다. 그 다음은 출력 근처 DequantizeLinear9,898,916.4cycles와 입력 QuantizeLinear9,282,777.7cycles였다. 이는 배치·형식 변환을 줄이는 실험의 근거다. cycle 항목이 모두 독립 구간이라고 가정하거나 합산해서 wall time 절감량을 예측하지 않는다. FP16과 INT8 실행의 실제 주파수도 확인되지 않았다.

현재 host I/O는 둘 다 FP32이며 입력49,766,400bytes/출력24,883,200bytes다. 다음 비교 후보는 U8 I/O와 배치 변환 감소다. 그래프 경계의 변환을 제거하더라도 외부 전처리·양자화·출력 복원 비용이 사라진 것으로 취급하지 않고 실제 파이프라인에서 별도 측정해야 한다. 개선은 아직 입증되지 않았다.
