# Cemu NPU Release RC1

릴리즈 기반 NPU 전용 승격 후보입니다. 기존 GPU LSFG 옵션과 Lossless.dll 의존성은 제거했습니다. 기존 v4 및 네 가지 기준 배포본은 유지됩니다.

실행 파일: `runtime/Cemu-NPU-Release.exe`

1. 일반 설정 → 그래픽 → **NPU processing**에서 **1080p / Standard** 또는 **720p / Performance**를 선택합니다. 처음에는 1080p입니다.
2. 해상도 선택은 **다음 게임 실행부터 적용**됩니다. 게임 실행 중 변경했다면 게임을 다시 시작합니다.
3. 게임에서 **NPU frame generation** 체크를 켭니다. 체크 OFF에서는 원본을 그대로 표시합니다. 앱 시작 때는 OFF입니다.

ON일 때 원본 프레임과 생성 프레임 모두 선택한 처리 해상도를 거쳐 현재 창/전체화면 크기로 출력합니다. 720p는 연산량을 줄이는 대신 세부 표현이 낮아질 수 있습니다. 원본 프레임 하나를 버퍼링하므로 약 한 프레임의 지연이 추가됩니다. 늦게 도착한 생성 프레임은 버립니다. FPS는 받아들여진 present 수이며 실제 디스플레이 스캔아웃을 측정한 값은 아닙니다.

CPU 검사와 빌드만 완료했습니다. 새 720p 모드와 NPU 독립 빌드는 아직 실기 검증 전입니다. 사용자가 직접 1080p/720p ON·OFF, 창 전환 및 화질을 확인한 뒤 네 가지 정식 버전에 반영할 예정입니다. 720p 속도 향상 폭은 아직 측정하지 않았습니다.

독립 모듈 검사를 원하면 컴퓨터를 사용할 수 있는 시간에 PowerShell에서 아래 명령을 직접 실행합니다. Cemu는 실행하지 않지만 GPU/NPU를 사용합니다. 실행 중인 게임은 먼저 정상 종료합니다.

```powershell
& '.\run-module-check.ps1' -Height 720 -Run
```

`-Run`을 생략하면 파일·드라이버 해시만 확인합니다. `-Height 1080`도 지원합니다. 기록은 `evidence`에 남고 강제 종료는 하지 않습니다. 모듈 검사 성공은 게임 화질이나 프레임 페이싱의 검증을 뜻하지 않습니다.

`runtime/portable`은 v4 설정의 독립 복사본이고 기존 MLC 경로를 그대로 사용합니다. 세이브는 복사하거나 수정하지 않았습니다. 원본 소스 변경분과 모듈/셰이더 소스는 `source-overlay`, `module-source`에 보존했습니다.
