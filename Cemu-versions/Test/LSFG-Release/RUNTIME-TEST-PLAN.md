# 실제 실행 시험 — 사용자 시간 승인 후

시험 대상: 순정 Release 기준의 `runtime-experiment/Cemu-lsfg.exe`. 공식 원본/SE 실행 파일과 혼동하지 않는다. `LSFG-TEST-BUILD.json`의 해시와 일치해야 한다. 원본 설치 설정/세이브는 수정하지 않는다.

1차는 약 10~15분을 요청한다. Cemu 화면 전환과 키보드/마우스 조작을 포함한다. 사용자 답변 전 실행하지 않는다. 아래 순서는 실제 결과에 따라 중단될 수 있으며, 강제 종료 타이머는 없다.

1. **OFF 준비 및 출력:** 원래 설정에서 시작한다. 창 제목 `[LSFG TEST]`, `Startup READY/OFF`의 shaders=51/pipelines=51/generated=0 확인. 야숨 타이틀과 실제 플레이 화면을 확인한다. 초기 준비 뒤 OFF에서 생성 카운터가 증가하지 않아야 한다.
2. **ON:** Graphics 체크박스를 켠다. WARMING 3회 동안 원본을 표시하고 이후 Generated 로그가 나오는지 확인한다. 화면 오류, 지연, 생성 처리 시간, 본래 게임 FPS를 따로 기록한다. 게임 FPS 표시만으로 2X 출력 성공을 주장하지 않는다.
3. **OFF → ON:** 화면은 OFF 동안 원래 경로로 돌아오고 생성 카운터가 멈춰야 한다. 다시 ON하면 이력을 새로 준비한다. 크기 변경 없는 실행의 종료 로그에서 context_builds=1, history_clears 증가를 확인한다.
4. **정상 종료:** UI로 종료하여 실제 종료 코드, 로그, Windows 오류 기록을 함께 판정한다. EXE/설정/로그 해시와 화면 관찰을 실행별 기록에 남긴다.

1차가 정상이어도 전체 성공은 아니다. 별도 실행에서 크기 변경/최소화·복귀/FSR 경로를 확인한다. 이전 공식 순정의 960x540 + 창 1050x740 조합은 0xC0000005로 종료됐으므로 그대로 반복하지 않는다. FSR 비교는 한 번에 한 설정만 바꾸고 공식 순정과 시험판의 조건을 일치시킨다. 시간 승인이 끝나면 다음 구간 시간을 다시 요청한다.

남은 품질 판정: 동일 프레임 입력의 알려진 경계 5픽셀 오차, 실제 중간 프레임의 적합성, 출력 cadence/성능. 이 항목과 안정성 확인 전에는 네 유지 버전에 반영하지 않는다.
