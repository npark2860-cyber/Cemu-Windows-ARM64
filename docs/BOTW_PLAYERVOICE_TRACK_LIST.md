## Intended use

v4 of the sound-source tracer should discover `PlayerVoice.bars` inside `TitleBG.pack`, register its BFWAV fingerprints, and resolve runtime AX voices to these exact `PVxxx_xx` identifiers.

Primary validation target:

```text
AX voice
  -> TitleBG.pack::Sound/Resource/PlayerVoice.bars
  -> PVxxx_xx
```

After that, controlled in-game actions can build a second semantic mapping document:

```text
PVxxx_xx -> confirmed action/context
```

Do not infer semantic meaning from the numeric PV identifier alone.
