NPU messages use the existing Cemu `_()` / `_tr()` translation functions. Merge `ko.po` into the existing `cemu` catalog; preserve all existing messages. `npu.pot` is the template for other locales. Untranslated messages fall back to English. `bin/resources/ko/cemu.mo` already contains the merged Korean messages; after changing `ko.po`, run `python i18n/npu/merge_catalog.py bin/resources/ko/cemu.mo i18n/npu/ko.po`.
